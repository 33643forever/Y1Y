# Roadmap

## 已完成

1. **最低 macOS 版本统一** (26.0)
2. **Markdown 渲染** — 常用块级和行内格式，含流式节流解析和未闭合降级
3. **代码块独立复制按钮**
4. **用户滚动优先**
5. **窗口缩放与尺寸记忆** — AI 回复页可拖拽缩放（最小 380×360），尺寸跨会话保持
6. **图钉固定** — 多窗口固定，浮动层级
7. **多窗口管理** — 独立会话，自动错开
8. **OpenRouter 余额迁移** — 浮窗移除余额，设置页新增余额与连接状态
9. **请求超时修复** — `timeoutInterval = 30`，解决请求卡"处理中"
10. **推理开关修复** — 关闭时不发送推理参数，避免模型误开启
11. **单元测试** — 23 项测试（Markdown、面板几何、账户状态、Mock 网络）
12. **文档更新** — README、需求说明、技术方案
13. **文件结构重组** — 按功能划分目录
14. **社区模板** — GitHub Issue 模板（Bug 报告 + 功能建议）

## 发布渠道

目前仅通过 GitHub Releases 发布。反馈渠道计划启用 GitHub Issues。

## 未来可能方向

以下方向根据代码中的 TODO 和已知推断列出，未经产品确认：

### 近期可能性

- **自定义全局快捷键** — 目前硬编码为 `⌘E`，`HotkeyConfig` 模型已存在但尚未实际用于快捷键注册
- **代码语法高亮** — 代码块目前为纯等宽字体，无高亮
- **图像输入支持** — README 路线图中提及，当前未实现

### 已知需调查

- **OpenRouter 请求偶尔长时间停留在"处理中"** — 已添加 30 秒超时，但实际服务端响应速度需用户手工验收确认。可能还需要 per-line 空闲超时保护

### 架构层面

- **AIService 进一步拆分** — 当前聊天流、模型列表、推理控制集中在一个类中，可拆分为 `ChatStreamingClient`、`ModelCatalogClient` 等
- **设置页 UI 优化** — 当前为基本功能布局
- **多语言支持** — 当前 UI 均为中文硬编码
- **可访问性增强** — 辅助功能标签基本覆盖，但可进一步优化

## 不做 (已确定)

- 浮窗位置持久化
- 固定状态持久化
- "恢复默认窗口大小"入口
- 表格、图片、数学公式、HTML、Mermaid 等 Markdown 扩展语法
- OpenRouter 以外 API 的余额查询
