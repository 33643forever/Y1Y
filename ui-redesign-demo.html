什么是 RAG？

RAG（Retrieval-Augmented Generation）是一种将信息检索与 LLM 相结合的架构。

工作流程

  1. 检索 — 从知识库中检索相关文档
  2. 增强 — 将文档与问题拼接
  3. 生成 — LLM 生成带有依据的回答
RAG 可以有效缓解 LLM 的"幻觉"问题。
Python
qa = RetrievalQA.from_chain_type(
    llm=OpenAI(),
    retriever=vectorstore.as_retriever()
)
